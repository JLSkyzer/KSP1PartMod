# KSP1PartMod

A KSP2 Redux mod that puts the KSP1 parts imported by Redux (from `mods/KSP1`) into the tech tree of exploration campaigns, so they can be researched and used there.

Status: scaffold (0.1.0). It builds and loads, and logs `[KSP1PartMod] loaded 0.1.0`. The tech tree placement is not implemented yet.

Requires KSP2 Redux 26w42c or later and Space Warp 2.

## Build

Unity 6000.6.0f1 with the Redux SDK template 26w42c. Run `Deploy to Zip File` (ThunderKit) to produce `Deploy/KSP1PartMod.zip`. Unzip it into the game's `mods` folder.
